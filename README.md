# All In · ניהול שולחן פוקר

אפליקציית WEB + PWA לניהול ערבי פוקר: שולחן עם קוד קבוע, קופאי לכל ערב, בקשות צ'יפים עם צילום הוכחה, ספירת צ'יפים מתמונה לפי צבעים, סיכום "מי חייב למי" עם שיתוף לוואטסאפ, וסטטיסטיקות לאורך זמן.

**Stack:** Next.js 15 (App Router) על Vercel · Supabase (Postgres, Google Auth, Realtime, Storage) · Tailwind 4 · Claude vision לספירת צ'יפים.

## מה יש בגרסה הזו

- **כניסה עם Google** בלבד.
- **שולחנות:** כל משתמש פותח שולחן עם קוד קבוע של 6 תווים ונהיה מנהל. הצטרפות בקוד דורשת אישור מנהל. הזמנה אישית בוואטסאפ/מייל מקשרת את הנרשם לפרופיל שהמנהל יצר, עם כל ההיסטוריה.
- **מנהלים:** הוספה/הסרה של שחקנים, מנהלי משנה, מחיקה לצמיתות (חסומה כשיש חוב פתוח; שחקן עם היסטוריה מוסתר כדי לא לשבור סיכומים ישנים).
- **ערכות צ'יפים:** צבעים וערכים, נשמרות לשולחן ונבחרות בכל ערב.
- **פתיחת ערב:** ערכה, כמה צ'יפים בכניסה וכמה זה עולה, מי משחק, ומי הקופאי. הכל נזכר מהערב הקודם.
- **ערב חי (בזמן אמת):** מסך שולחן פוקר עם השחקנים סביבו וכמה כל אחד קנה, ומתחתיו דשבורד "מי קנה ובכמה" ויומן פעולות.
  - שחקן מבקש צ'יפים לפי צ'יפים או לפי סכום. הקופאי מקבל התראה ורואה הצעה איזה צ'יפים לתת.
  - הקופאי מוסר, מצלם את הערימה, והתמונה נספרת. אם זה תואם, הבקשה מאושרת ונוספת לחוב.
  - אם לא תואם: הקופאי בוחר "מסרתי בפועל X" (תיקון ידני, מתועד) או "הזיהוי שגוי" (נשלח לאישור מנהל).
  - שחקן שקם באמצע: סופרים לו צ'יפים, החוב שלו ננעל ולא יתווסף לו חוב בהמשך.
  - מנהל יכול להחליף קופאי ולהוסיף שחקנים באמצע ערב.
- **סגירת ערב:** סופרים לכל שחקן (ידנית או מתמונה), רואים אם יש חוסר/עודף מול מה שחולק, ומקבלים מינימום העברות "מי מעביר למי". בסגירה התמונות נמחקות.
- **אחרי הערב:** סיכום עם שיתוף לוואטסאפ, סימון "שולם" על ידי המקבל, "החובות הפתוחים שלי" במסך הבית של השולחן.
- **סטטיסטיקות:** טבלת שולחן, סה"כ וממוצע לערב, ערב הכי טוב, אחוז ניצחונות, גרף רווח מצטבר, ותארים (מוביל, ערב השיא, מלך הריביי).
- **PWA:** ניתן להתקנה למסך הבית (manifest + service worker).

## הקמה (פעם אחת)

1. **Supabase:** צור פרויקט ב-[supabase.com](https://supabase.com). המיגרציות ב-`supabase/migrations` רצות אוטומטית בהעלאה.
2. **Google login:** ב-Google Cloud Console צור OAuth Client (Web). ב-Authorized redirect URIs הוסף `https://YOUR-PROJECT.supabase.co/auth/v1/callback`. ב-Supabase: Authentication → Providers → Google, הדבק Client ID ו-Secret. ב-Authentication → URL Configuration הוסף את כתובת האתר שלך (ו-`http://localhost:3000` לפיתוח) ל-Redirect URLs.
3. **משתני סביבה:** העתק `.env.example` ל-`.env.local` ומלא. `ANTHROPIC_API_KEY` אופציונלי: בלעדיו הכל עובד וספירת הצ'יפים ידנית.
4. **הרצה מקומית:** `npm install` ואז `npm run dev`.
5. **פריסה:** ל-Vercel, לפי [docs/DEPLOY.md](docs/DEPLOY.md).

## APK לאנדרואיד (בהמשך)

הדרך המומלצת היא TWA (Trusted Web Activity), שעוטף את ה-PWA כאפליקציה אמיתית:

```bash
npx @bubblewrap/cli init --manifest https://YOUR-DOMAIN/manifest.webmanifest
npx @bubblewrap/cli build
```

אחרי זה מעלים את קובץ `assetlinks.json` שנוצר ל-`public/.well-known/` כדי שהאפליקציה תיפתח בלי שורת כתובת.

## פיתוח

- `npm test`: בדיקות לחישובי חוב, איזון פערים, חלוקה לצ'יפים וסטטיסטיקות.
- `npm run lint`, `npm run build`.
- `/preview` (רק בפיתוח): תצוגת עיצוב עם נתוני דוגמה של ערב חי וסיכום ערב.
